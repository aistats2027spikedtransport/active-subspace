# Learning spiked transport maps via active subspace

## Overview

Optimal transport characterizes high-dimensional distributions by learning maps from a tractable reference to the complex target on $R^d$. Given that these maps are costly to solve directly in the ambient dimension, we study the setting in which the target is low-rank relative to the reference: there is an unknown $r$-dimensional subspace with r ≪ d. Under this assumption, we show that the entropic transport map decomposes exactly into an $r$-dimensional map composed with the identity on the orthogonal complement, and estimating it reduces to alternating between fitting the reduced map and updating the subspace. We identify the leading eigenspace from an empirical outer-product matrix based on gradients of the log-target density that we iteratively estimate based on the current map. Finally, we validate the theory in two experiments: a synthetic study with a known ground-truth subspace and a large-scale application to CITE-seq single-cell measurements of ambient dimension up to 22,050. We show that the compressed map matches the target distribution’s spread substantially better than an uncompressed map fit directly in the ambient dimension.

## File Structure

The repo is structured as:

-   `Code/function` contains the functions needed for the algorithm.
-   `Code/load_data` is used to generate the csv for the data with D=22050 dimensions.
-   `Code/synthetic_data` runs the algorithm on synthetic data.
-   `Code/d_100_pipeline` and `Code/d_22050_pipeline` runs the algorithm with both sets of data.
-   `Code/bias_variance_tradeoff`, `Code/convergence`, and `Code/PCA` contains the code for the other plots.
-   `Data/citeseq` is the csv for the data with D=100 dimensions.
-   `Data/convert_to_csv` can be used to generate the csv for the data with D=22050 dimensions.
-   `Figures` contains all the figures generated by the code.
